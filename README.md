# Smart Mirror

This project is a **React-based smart mirror interface** designed for personal use. It runs in fullscreen/kiosk mode and displays a rotating dashboard of useful information.

## Features

### Letterboxd Movies
- Uses the **Letterboxd RSS Service** to show **recent movies I’ve watched**
- Includes my personal **star rating**
- Displays each movie’s **poster artwork**

### Spotify Listening
- Integrates with a service that pulls my **streaming history**
- Shows the **top 5 albums from the past week**
- Displays:
  - **Album cover**
  - **Number of listens**

### Wordle
- Shows my **daily Wordle score**
- Renders the results in a **classic Wordle-style grid**
- Includes a **reminder** to complete Wordle each day

### Weather
- Displays the **forecast for the day**
- Hourly view across the **next ~8 hours**

### Time & Date
- Minimal clock and calendar view optimized for mirror display

## Status
Actively being developed. UI and widget layout are still evolving as features are refined.
